OceanLab 2.1.2 — Windows 7 64 位安装版

本版本包含当前 2.1.2 绿色版全部更新：PL / AB 紧凑布局和图标、
仅显示完整文件名的悬停提示、直接 / 间接 Tauc，以及数字饱和度和颜色提示。

2.1.2 新增：普通暂停和取消单次保留仪器连接，等待当前设备操作结束后可直接再采。
取消的数据不更新曲线、不进入保存候选；超时或设备异常仍释放连接。

双击 OceanLab-2.1.2-win7-x64-setup.exe，按提示安装。
默认安装到当前用户的 LocalAppData\Programs\OceanLab-Win7，无需管理员权限。
桌面和开始菜单提供 OceanLab (Win7) 快捷方式。

以后升级：先退出 OceanLab，再运行新版安装包。安装包沿用上次位置，
更新程序和快捷方式，并清理旧版本的程序文件。无需手动替换 DLL。
同版本安装可修复程序；不允许覆盖安装更旧的版本。
安装和卸载不会删除 LocalAppData\OceanLab\settings.json 或采集数据。
从绿色版迁移：直接安装即可沿用当前 Windows 用户的设置；之后使用新快捷方式。
绿色版目录保留在原位置，确认安装版可用后可自行整理。

本安装包离线包含 Python 3.7.9、Tkinter 和程序运行库。
2.1.2 支持扫描之间暂停平均；等待当前扫描结束后跳过剩余次数，保留仪器连接。
本次同版本更新包含 AB 分组卡片、整组显隐 / 移除按钮，以及直接 / 间接 Tauc 导出默认命名。
分组图标放在标题前，删除需二次确认；最后一组删除后回到分析组 1，唯一空组禁止删除。
Tauc 默认导出名使用 Tauc_Direct_2 和 Tauc_Indirect_1-2。
真机仍需另行安装兼容的 64 位 OceanDirect 和 USB 驱动。
不安装、不更新、不删除 OceanDirect、驱动、固件或校准数据。
不要把安装位置选择为驱动目录或光谱数据目录。
升级过程中请勿启动 OceanLab。设置位置和数据保存位置保持原规则。

安装程序使用 Inno Setup 6.2.2；许可证见 INNO_SETUP_LICENSE.txt。

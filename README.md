# OceanLab 光谱采集软件

Windows 10/11 光谱采集与分析桌面软件，当前版本 `0.3.0`。支持模拟模式、OceanDirect 真机采集、PL 荧光和 AB 吸收分析。

- 中文使用说明：[OceanLab/README_zh-CN.md](OceanLab/README_zh-CN.md)
- 第三方与版权说明：[OceanLab/NOTICE_zh-CN.md](OceanLab/NOTICE_zh-CN.md)
- 驱动说明：OceanDirect SDK 和 USB 驱动不随项目提供，连接真实仪器时请从官方渠道自行获取。

快速运行：

```powershell
cd OceanLab
python launcher.py
```

本项目是 Windows 桌面软件，不是 GitHub Pages 网站。提交前请阅读第三方与版权说明。
